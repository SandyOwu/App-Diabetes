Esta app móvil está dirigida a personas diabéticas, ayuda a saber los carbohidratos de más de 200 alimentos según el SMAE (Sistema Mexicano de Alimentos Equivalentes).



Cuenta con búsqueda manual por medio de palabras clave sin tomar en cuenta minúsculas, mayúsculas o acentos. Además, cuenta con un reconocimiento de alimentos por medio de cámara o fotografía.



Se usó Java en AndroidStudio para su desarrollo, Firebase para guardar la base de datos y Teachable Machine para el reconocimiento de alimentos.



Todo se creó al idioma español.
